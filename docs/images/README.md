# Branding assets

Original artwork for this project, created by Lee Gillie.

| File | Use |
|---|---|
| `LightburnConfigProject.png` | Wide banner. Used at the top of the repository [README](../../README.md) |
| `LightburnConfigIcon.png` | Square icon. Intended for GitHub's **social preview** (Settings → General → Social preview) and as an organisation/avatar image |

## Two things to keep in mind

**The banner is aspirational.** It says "Tested & Tuned by the Community", which describes where
this project is going rather than where it is. The README carries a caption saying so, and points
readers at the [feature inventory](../02-feature-inventory.md) for real status. If the artwork is
ever re-rendered, that phrasing is worth revisiting.

**The lens part numbers shown on the banner are decorative**, not photographs of real hardware.
They are not evidence and must not be cited as such. Real, verified hardware details live in
[`captures/`](../../captures/).
